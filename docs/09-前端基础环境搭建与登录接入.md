# 基于工业软件企业后台管理系统数字化运营——前端基础环境搭建与登录接入说明（Vue3 + Vite）

课程：《工业软件开发综合实训》（课程代码 192434303）　项目：industrial_admin / web　版本：V1.0

## 11 前端基础环境搭建与登录接入

前端的第一步不是“画出所有页面”，而是先把三件事跑通：页面能跑起来（构建与热更新正常）、请求能到后端（跨域被代理解决）、身份能被识别（令牌自动携带且失效能回登录页）。这三件事跑顺后，后续每加一个业务页面都是复制同一套模式，不会反复在环境上踩坑。

### 11.1 技术选型与版本

前端采用 Vue 3 组合式 API（script setup）编写，构建工具用 Vite，UI 用 Element Plus，请求用 Axios，图表规划用 ECharts。选择 Vite 的原因是它基于原生 ES 模块做按需编译，冷启动和热更新都比传统打包工具快，配合 Vue 单文件组件开发体验顺畅；Element Plus 提供与本项目“后台管理”定位相符的表格、表单、树控件，登录页的表单校验也能直接复用它的 Form 组件。

### 11.2 项目初始化命令

初始化使用 Vite 官方的 create 命令并指定 vue 模板，随后按需安装业务依赖，不引入多余的脚手架（如 TypeScript 模板、状态管理库），保证工程结构简单、报告里能逐行说明。命令在项目根目录 industrial_admin 下执行，前端工程落在 web 子目录，与后端形成前后端同仓的结构，便于一次提交同时包含两端代码。

```vue

# 5. 打包与本地预览（产物在 dist/）

npm run preview
```

### 11.4 跨域代理配置

浏览器同源策略会拦截 5173 端口对 8080 端口的直接请求。解决方式是在 Vite 开发服务器上配置代理：前端统一请求 /api/v1/... 这样的相对路径，由开发服务器转发到后端，浏览器看到的始终是同源请求，因此不需要后端开放 CORS（虽然本项目后端也开了 CORS 中间件，但代理能让本地调试更稳定，也不依赖它）。代理地址默认指向 http://127.0.0.1:8080，并支持用环境变量 PROXY_TARGET 覆盖——本机 8080 已被其它进程占用，联调时用 PROXY_TARGET 指向 18080 完成验证，配置本身无需改动。

```vue
import { fileURLToPath, URL } from 'node:url'
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

// Vite 配置：开发期用代理解决跨域，生产期由 Nginx 反向代理同一路径
export default defineConfig({
  plugins: [vue()],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    }
  },
  server: {
    host: '127.0.0.1',
    port: 5173,
    // 代理规则：浏览器请求 /api/xxx，开发服务器转发到后端，避免浏览器跨域
    proxy: {
      '/api': {
        // 后端地址；默认 8080，可用环境变量 PROXY_TARGET 覆盖（如后端改端口时）
        target: process.env.PROXY_TARGET || 'http://127.0.0.1:8080',
        changeOrigin: true,
        ws: false
      }
    }
  },
  build: {
    outDir: 'dist',
    sourcemap: false
  }
})
```

### 11.5 Axios 请求封装

**令牌携带：**请求拦截器从 localStorage 读取 token，存在则写入 Authorization: Bearer <token>。令牌只在一处注入，页面里不需要每个请求手工加头，也不会因为某个页面漏加而在后端返回 401。

**统一错误处理：**后端所有接口都返回 {code, message, data} 三段结构。响应拦截器判断 code：为 0 时直接把 data 返回给业务层（页面拿到的就是纯数据，不用每次 res.data.data）；非 0 时统一弹 Element Plus 的错误提示并 reject。code 为 40100（未登录或令牌失效）时额外清除本地令牌并跳回登录页，避免带着废令牌反复请求。网络层异常单独处理：有响应体时取后端 message，无响应时区分超时与服务未启动，给的是“检查后端是否已启动”这类可操作提示，而不是笼统的“请求失败”。

```vue
import axios from 'axios'
import { ElMessage } from 'element-plus'
import router from '@/router'

// 统一请求实例：baseURL 走 /api/v1，开发期由 vite 代理转发到后端
const service = axios.create({
  baseURL: '/api/v1',
  timeout: 10000,
  headers: { 'Content-Type': 'application/json;charset=utf-8' }
})

// 请求拦截：自动携带 token；登录接口本身不需要
service.interceptors.request.use(
  (config) => {
    const token = localStorage.getItem('token')
    if (token) {
      config.headers.Authorization = `Bearer ${token}`
    }
    return config
  },
  (error) => Promise.reject(error)
)

// 响应拦截：后端统一返回 {code, message, data}，这里只把 data 交给业务层
service.interceptors.response.use(
  (response) => {
    const body = response.data
    if (body.code === 0) {
      return body.data
    }

    // 业务错误：40100 未登录/令牌失效，40101 口令错误等，统一提示后拒绝
    ElMessage.error(body.message || '请求失败')
    if (body.code === 40100) {
      localStorage.removeItem('token')
      router.push('/login')
    }
    return Promise.reject(new Error(body.message || '请求失败'))
  },
  (error) => {
    // 网络层错误：超时、后端未启动、跨域被拒等
    let msg = '网络异常，请稍后重试'
    if (error.response) {
      const status = error.response.status
      const body = error.response.data || {}
      msg = body.message || `请求失败（HTTP ${status}）`
      if (status === 401) {
        localStorage.removeItem('token')
        router.push('/login')
      }
    } else if (error.code === 'ECONNABORTED') {
      msg = '请求超时，请检查后端服务是否已启动'
    }
    ElMessage.error(msg)
    return Promise.reject(error)
  }
)

export default service
```

### 11.6 登录页与路由守卫

**登录流程：**用户输入账号与口令，前端先做必填与长度校验（减少无效请求），通过后调用 /auth/login；成功时后端返回 token、用户信息、权限点与菜单，前端把 token 与 user 存进 localStorage，再跳转到首页。口令错误时后端返回 401/40101，拦截器弹出“账号或口令错误”，页面停留在登录页且不写入任何令牌。

**守卫设计：**路由守卫在每次跳转前检查 localStorage 中是否存在 token：目标页非公开且无 token 时跳登录页，并把原路径放进 query.redirect，登录成功后回到原页面；已登录再访问登录页则直接回首页，避免重复登录。守卫只做“是否带令牌”的粗判，真正的权限校验仍在后端按权限点执行，前端不承担安全职责。

```vue
<template>
  <div class="login-page">
    <el-card class="login-card" shadow="always">
      <div class="login-title">工业软件企业后台管理系统</div>
      <div class="login-sub">数字化运营平台 · 统一登录入口</div>

      <el-form ref="formRef" :model="form" :rules="rules" size="large" @keyup.enter="onSubmit">
        <el-form-item prop="username">
          <el-input v-model="form.username" placeholder="请输入登录账号" clearable />
        </el-form-item>
        <el-form-item prop="password">
          <el-input
            v-model="form.password"
            type="password"
            placeholder="请输入登录口令"
            show-password
            clearable
          />
        </el-form-item>
        <el-form-item>
          <el-button type="primary" class="login-btn" :loading="loading" @click="onSubmit">
            {{ loading ? '登录中…' : '登 录' }}
          </el-button>
        </el-form-item>
      </el-form>
    </el-card>
  </div>
</template>

<script setup>
import { reactive, ref } from 'vue'
import { useRouter, useRoute } from 'vue-router'
import { ElMessage } from 'element-plus'
import { login } from '@/api/auth'

const router = useRouter()
const route = useRoute()

const formRef = ref(null)
const loading = ref(false)
const form = reactive({ username: '', password: '' })

// 前端只做必填与长度校验，后端仍会再校验一次，前端校验的目的是减少无效请求
const rules = {
  username: [
    { required: true, message: '请输入登录账号', trigger: 'blur' },
    { min: 2, max: 50, message: '账号长度应为 2 到 50 个字符', trigger: 'blur' }
  ],
  password: [
    { required: true, message: '请输入登录口令', trigger: 'blur' },
    { min: 6, max: 32, message: '口令长度应为 6 到 32 位', trigger: 'blur' }
  ]
}

async function onSubmit() {
  const valid = await formRef.value.validate().catch(() => false)
  if (!valid) return

  loading.value = true
  try {
    const data = await login({
      username: form.username.trim(),
      password: form.password
    })

    // 令牌与用户信息落本地，后续请求由 axios 拦截器自动带上
    localStorage.setItem('token', data.token)
    localStorage.setItem('user', JSON.stringify(data.user || {}))
    localStorage.setItem('permissions', JSON.stringify(data.permissions || []))
    localStorage.setItem('menus', JSON.stringify(data.menus || []))

    ElMessage.success('登录成功，欢迎 ' + (data.user?.realName || form.username))
    const redirect = route.query.redirect || '/home'
    router.push(String(redirect))
  } catch (e) {
    // 错误提示已由 axios 响应拦截器统一弹出，此处只结束加载状态
  } finally {
    loading.value = false
  }
}
</script>
```

```vue
import { createRouter, createWebHistory } from 'vue-router'

// 路由表：登录页公开，其余页面需要已登录（登录状态以 localStorage 中的 token 为准）
const routes = [
  {
    path: '/login',
    name: 'Login',
    component: () => import('@/views/Login.vue'),
    meta: { public: true, title: '登录' }
  },
  {
    path: '/',
    redirect: '/home'
  },
  {
    path: '/home',
    name: 'Home',
    component: () => import('@/views/Home.vue'),
    meta: { title: '运营看板' }
  },
  {
    path: '/:pathMatch(.*)*',
    redirect: '/home'
  }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

// 全局前置守卫：无 token 且目标页非公开时，跳回登录页
router.beforeEach((to) => {
  const token = localStorage.getItem('token')
  if (!to.meta.public && !token) {
    return { path: '/login', query: { redirect: to.fullPath } }
  }
  if (to.path === '/login' && token) {
    return { path: '/home' }
  }
  return true
})

export default router
```
